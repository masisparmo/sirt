Cara Mendapatkan ID RT (Link Khusus)

Agar warga RT Anda dapat mengakses aplikasi ini dengan mudah menggunakan link khusus (misal: https://sirt.isparmo.com/?id=rt08-royal2), Anda perlu mendaftarkan database Anda ke Master Direktori.

  1. Lakukan langkah instalasi backend (Poin 1-3 di bawah) sampai mendapatkan URL Web App.
  2. Hubungi Admin Pusat SIRT Pintar via WhatsApp: 0812-1083-060.
  3. Berikan Nama RT/Kelurahan (misal: RT08 Taman Royal 2) dan URL Web App Anda.
  4. Admin akan memberikan ID RT (misal: rt08-royal2).
  5. Bagikan link https://sirt.isparmo.com/?id=rt08-royal2 kepada warga.
1

Buat Database Google Sheet

Buat Spreadsheet baru di Google Drive Anda. Biarkan kosong, script akan otomatis membuat kolom.

2

Pasang Kode Backend (V19 - Dues Management)

Buka menu Ekstensi (Extensions) > Apps Script di Google Sheet Anda. Hapus semua kode yang ada, lalu SALIN SEMUA KODE DI BAWAH INI dan tempelkan ke sana.

3

Deployment Ulang (WAJIB)

Setelah paste kode baru: Klik Terapkan (Deploy) > Kelola Deployment > Edit > Versi Baru > Terapkan. Salin URL baru.
